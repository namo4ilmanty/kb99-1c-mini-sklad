# Проверка «Мини-Склада»

Сценарии ручной проверки по функциям: что сделать в режиме 1С:Предприятие и что должно получиться.
Прогоняйте раздел после каждого изменения, которое затрагивает его функцию.
Пока проверки ручные; план — перевести их в автотесты: сценарии Vanessa Automation на Gherkin (`features/`)
и модульные тесты YAxUnit.

## Подготовка

База — по разделу [«Как открыть с нуля»](../README.md#как-открыть-с-нуля). В справочниках — хотя бы один товар
и один контрагент.

## Ввод строк в документах

Одинаково для «Поступления товаров» и «Реализации товаров».

1. Введите в строке товаров количество и цену: сумма строки пересчитывается — количество × цена.
2. Отрицательные количество и цену ввести нельзя: поле не принимает минус.
3. Количество принимает три знака после запятой, например 0,125; цена — два.

## Контроль остатков при реализации

1. Проведите «Поступление товаров»: любой товар — 10 шт.
2. Проведите «Реализацию товаров» на тот же товар — 12 шт. Документ не проведётся, в сообщениях будет
   «Недостаточно товара «…»: нужно 12, на складе 10».
3. Исправьте количество на 10 и проведите: документ проводится. Повторное проведение тоже проходит —
   перед проверкой старые движения документа очищаются.
4. Реализация без строк не проводится: табличная часть «Товары» обязательна.
5. Перенесите дату проведённой реализации на день позже (дата поступления должна остаться раньше) и перепроведите:
   документ проводится, ложной нехватки нет.
