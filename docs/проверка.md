# Проверка «Мини-Склада»

Сценарии ручной проверки по функциям: что сделать в режиме 1С:Предприятие и что должно получиться.
Прогоняйте раздел после каждого изменения, которое затрагивает его функцию.
Пока проверки ручные; план — перевести их в автотесты: сценарии Vanessa Automation на Gherkin (`features/`)
и модульные тесты YAxUnit.

## Подготовка

База — по разделу [«Как открыть с нуля»](../README.md#как-открыть-с-нуля). В справочниках — хотя бы один товар
и один контрагент.

## Ввод строк в документах

Одинаково для «Поступления товаров» и «Реализации товаров».

1. Введите в строке товаров количество и цену: сумма строки пересчитывается — количество × цена.
2. Отрицательные количество и цену ввести нельзя: поле не принимает минус.
3. Количество принимает три знака после запятой, например 0,125; цена — два.
4. Сумму строки вручную изменить нельзя: колонка только для просмотра.

## Контроль остатков при реализации

1. Проведите «Поступление товаров»: любой товар — 10 шт.
2. Проведите «Реализацию товаров» на тот же товар — 12 шт. Документ не проведётся, в сообщениях будет
   «Недостаточно товара «…»: нужно 12, на складе 10».
3. Исправьте количество на 10 и проведите: документ проводится. Повторное проведение тоже проходит —
   перед проверкой старые движения документа очищаются.
4. Реализация без строк не проводится: табличная часть «Товары» обязательна.
5. Перенесите дату проведённой реализации на день позже (дата поступления должна остаться раньше) и перепроведите:
   документ проводится, ложной нехватки нет.

## Продажи

1. Проведите «Реализацию товаров» с двумя строками (по каждому товару остатка должно хватать).
2. Откройте «Продажи» в разделе «Мини-Склад»: на каждую строку документа — запись с периодом = дате документа,
   регистратором = документу, товаром, контрагентом, количеством и суммой.
3. Измените количество в строке и перепроведите: старые записи заменились, задвоения нет.
4. Отмените проведение: записи из «Продаж» исчезли.
5. Реализация с нехваткой не проводится — и записей в «Продажах» не появляется.

## Обороты по товарам

1. Создайте новый товар, проведите его поступление на 10 шт. и реализацию на 3 шт.
2. Откройте «Мини-Склад → Отчеты → Обороты по товарам». Задайте период так, чтобы обе даты документов
   находились внутри него: начало — раньше первого документа, конец — не раньше конца дня второго документа.
3. Сформируйте отчёт: для нового товара начальный остаток — 0, приход — 10, расход — 3, конечный остаток — 7.
4. Задайте конец периода на конец дня поступления, но до реализации: приход — 10, расход — 0,
   конечный остаток — 10. Так проверяется остаток на дату.
5. Если документ текущего дня не попал в отчёт, проверьте время в параметре `КонецПериода`:
   «Начало этого дня» означает 00:00:00 и не включает более поздние документы этого дня.

## Печать реализации

1. Откройте Реализацию с двумя строками товаров и нажмите «Печать».
2. В табличном документе должны быть номер, дата, контрагент, номера строк, товары, количество, цены и суммы.
3. Сверьте итоговую сумму с суммой строк документа.
4. Сохраните Реализацию с контрагентом, но без строк, и нажмите «Печать»: шапка и итог 0 выводятся без ошибки.
